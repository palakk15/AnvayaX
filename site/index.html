Where the data comes from · freshness, coverage & free-use limits

Forecasts & current estimates

The forecast service serves NOAA GFS, ECMWF IFS, ECMWF AIFS, DWD ICON, ECCC GEM and JMA GSM forecasts. Current conditions and the seven-day overview use its automatic model selection. These are gridded estimates, not a nearby station reading. Model updates differ; hourly values may be interpolated.

Provider documentation ↗

Public access, responsibly

The free forecast API is for non-commercial use: fewer than 10,000 calls/day, 5,000/hour and 600/minute. Attribution is required. We cache forecasts for 15 minutes and locations for a day; availability and accuracy are not guaranteed.

Licence & terms ↗

PIN codes & official warnings

Places: GeoNames via the location service. PIN directory: third-party Postal PIN Code API. Postal results can use district coordinates, which are clearly labelled. IMD warnings are available through the official portal; no IMD alert feed is connected here.
