Weather models disagree. BharatBlend is a research system that calibrates their outputs, learns context-dependent weights, and explains every source's contribution—while showing exactly what evidence is still missing.

THE CORE IDEA

Adaptive blending, with a receipt

Static averages cannot express why a coastal rain event needs a different source mix from a long-lead temperature forecast. The gate conditions on lead, location, season, forecast regime and recent skill.

01

Eligibility first

A candidate enters the blend only if its variable, valid window, release time and trained calibrator match. Missing inputs trigger explicit exclusions.

02

Probabilistic weights

Each source is calibrated before an interpretable gate assigns context-specific weights. Rainfall tails and joint wind are handled as distributions.

03

Exact explanation

Inspect source weights, terms that changed each logit, event probability contributions and a counterfactual forecast with any source removed.

WHAT MAKES THIS DISTINCT

Trust is a model output.

The system reports a reason when a source is missing, a model version is unsupported, or a forecast cannot be verified. That is operationally useful information, especially during extremes.
